# Alfardos Management — الفردوس للإدارة

نظام محاسبة وإدارة أعمال عربي (RTL) مبني بـ Flutter و Firebase، يعمل على **Android** و **Windows**.

Arabic accounting & business management system — Flutter + Firebase, Android & Windows.

## المميزات
- لوحة تحكم: المبيعات والأرباح والمصروفات والتدفق النقدي، وديون العملاء ومستحقات الموردين.
- فواتير بيع وشراء (نقدي، آجل، جزئي) بمنتجات وخدمات، والخصم يتوزع على الأصناف.
- العملاء والموردون بكشوف حساب وأرصدة افتتاحية.
- التحصيل من العملاء والدفع للموردين، والخزائن والتحويلات، والمصروفات وبنودها.
- المنتجات والمخزون بمتوسط التكلفة المرجّح، والخدمات بتكلفتها وربحها.
- تقارير: الأرباح، والمبيعات، والمشتريات، والمصروفات، والديون، والخزائن، والخدمات، والمخزون، وسجل القيود. تصدير PDF و Excel/CSV.
- المستخدمون والأدوار والصلاحيات، وسجل تدقيق، وإشعارات.
- طباعة ومشاركة الفواتير والكشوف PDF بالعربي.

## المحرك المحاسبي
كل عملية مالية تتسجل كقيد متوازن في معاملة Firestore ذرية واحدة: الأرصدة والمخزون والإحصائيات وسجل التدقيق تتكتب مع بعض أو لا يتكتب منها شيء. الإلغاء يتم بقيد عكسي، ومفيش أي حذف للسجلات المالية. قواعد Firestore الأمنية بتتحقق إن أي تغيير في رصيد مربوط بقيد جديد بنفس المبلغ بالضبط.

التفاصيل الكاملة في [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## التشغيل
```bash
flutter pub get
flutter run -d windows              # Windows
flutter build apk --release         # Android
```
أول تشغيل: اختار "إعداد النظام لأول مرة" لإنشاء حساب المدير (مرة واحدة فقط).

## الاختبارات
```bash
flutter test
firebase emulators:exec --only firestore --project demo-alfardos "npm --prefix test/firestore_rules test"
```

## Firebase
- المشروع: `alfardos-mgmt`
- رفع القواعد والفهارس: `firebase deploy --only firestore,auth --project alfardos-mgmt`
- Storage (الشعار ومرفقات المصروفات) لازم يتفعل من الكونسول الأول.
